# 商品定價小幫手 MerchPricing 

> 視覺化圖表 Ｘ 拆解成本結構

專為創作者與微型電商打造的定價財務工具。從打樣、包裝到出貨，幫你精算每一筆隱藏成本，透過全視覺化圖表一眼看透金流與損益，定出不虧本的好價格。

## 🚀 線上使用 (Live Demo)

🔗 **[立即前往商品定價小幫手](https://chenchiaoyu.github.io/MerchPricing/)** （無須安裝或註冊，開箱即用）

## ✨ 核心功能 (Features)

*   **多維成本拆解**：自訂獨立支出項目（攤位租金、包材、車資等），不再漏算隱藏成本。
*   **精準反推售價**：設定目標毛利率，自動計算達到損益平衡所需的定價與銷量。
*   **視覺化圖表**：一眼洞悉營收流向與各項成本佔比。
*   **一鍵檔案管理**：支援快速匯入 / 匯出 CSV 檔案，輕鬆管理不同商品的定價策略。
